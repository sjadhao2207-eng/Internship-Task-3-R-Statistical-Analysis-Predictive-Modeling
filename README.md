# Week 3 - Statistical Analysis and Predictive Modeling using R

## Project Overview
This project performs statistical analysis and predictive modeling using the Titanic passenger dataset as part of the R Data Analyst Internship.

## Technologies Used
- R Programming
- Visual Studio Code
- Logistic Regression
- Statistical Hypothesis Testing
- Data Visualization

## Tasks Performed
- Data cleaning and preprocessing
- Descriptive statistical analysis
- Normality testing using Shapiro-Wilk
- Spearman correlation analysis
- Chi-square hypothesis testing
- Wilcoxon rank-sum test
- Logistic Regression model development
- Five-fold cross-validation
- Confusion matrix and ROC curve analysis
- Model performance evaluation

## Model Performance

| Metric | Result |
|---|---:|
| Accuracy | 79.10% |
| Precision | 74.60% |
| Recall | 69.12% |
| F1-score | 71.76% |
| ROC-AUC | 84.09% |
| Cross-validation Accuracy | 79.97% |

## Project Structure
- Dataset/ - Titanic dataset
- R_Scripts/ - R analysis scripts
- Outputs/Graphs/ - Generated visualizations
- Outputs/Results/ - Statistical results
- Outputs/Models/ - Saved predictive model
- Report/ - Word internship report
- Screenshots/ - Project screenshots
